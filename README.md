# Crafter project page

Source of the GitHub Pages site at <https://v1p0r.github.io/Crafter/>, served from this `gh-pages` branch.

- `index.html` holds all content. Author names, affiliations, the Paper/arXiv links, and the BibTeX author field are marked with `TODO` comments.
- `static/css/index.css`, `static/js/index.js`, `static/images/` hold the styling, copy-button/nav scripts, and figures.
- No build step. Edit, commit, push; Pages redeploys in about a minute.

The code and README for Crafter itself live on the `main` branch.
